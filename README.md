# 🛍️ Shopping Mall Customer Segmentation using K-Means Clustering

Welcome to my first Python project on Github!
In this project, I use  **K-Means Clustering** to segment shopping mall customers into 5 clusters based on features such as Age, Gender, Income Level, and SpendingScore

---

## 📊 Project Overview

This project is a beginner-level data science project that walks through the full machine learning workflow:
- Data loading and exploration
- Data cleaning and pre-processing
- Determining the optimal number of clusters
- Creating a K-Means Clustering Model
- Visualizations
- Interpreting the results

The goal is to segment customers to identify hidden patterns in shopping behavior.

---

## 🧠 Skills Demonstrated

- Data analysis using **Pandas**
- Data visualization using **Matplotlib**
- Machine Learning using **Sklearn**
- Developing and Interpreting a **K-Means Clustering** Model
- Writing clean and well-documented Python code

---

## 🗂️ Dataset

The dataset used is called "mallcustomers.csv". It includes features such as:
- Age
- Gender
- Income Level
- SpendingScore

The dataset is not mine to share.
